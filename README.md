# wojackgenerator

Движок для вертикальных (1080×1920) научно-мемных видео: озвучка ElevenLabs, вояк-ведущий, который ходит по кадру и тычет пальцем в нужные места карточки, карточки исследований в стиле PubMed и настоящие рисунки из статей.

Первый эпизод — **«How ibuprofen makes you a dwarf 💀»** (НПВП и зоны роста): `dist/nsaids-growth-plates.mp4`.

## Что изменилось по сравнению со старым проектом

| Было (ChatGPT, Python/Pillow) | Стало |
|---|---|
| Кадры рисовались попиксельно в Pillow, без сглаживания | Сцены — HTML/SVG, рендер в headless Chromium (векторная графика, нормальная типографика) |
| Ведущий стоял на месте; жест пальцем — отдельная картинка | Вояк-кукла: тело, отдельная «резиновая» рука с IK-наведением, липсинк рта по аудио. Перед жестом подходит к цели, разворачивается и тычет пальцем точно в объект (слово в цитате, точку на графике, клетку) |
| Тайминги анимаций вручную в секундах | Всё привязано к словам озвучки (`@dwarfs`, `@block#2`…): переозвучил — анимации сами встали на место |
| Подписи внизу, дублирующие лейблы | Субтитры подняты в полосу между карточкой и вояком (как на твоей разметке), лишние подписи убраны |
| Названия исследований текстом | Ссылка PubMed из сценария → автоматически карточка (название, «Автор et al. Журнал. Год.») через NCBI E-utilities |
| — | Настоящие рисунки из open-access статей (Caron 2021, Janssen 2017) с подсветкой нужных точек данных |
| Темп 66 с, длинные паузы | 50 секунд: паузы ужаты, речь ускорена без изменения тембра (atempo), исследования идут быстрым монтажом по ~2,5 с |
| Плоский фон | Бумажная текстура (волокна, заломы, зерно) с медленным дрейфом и «гуляющим» светом |

## Быстрый старт

```bash
npm install                      # sharp; playwright уже стоит в системе (Chromium из /opt/pw-browsers)
export ELEVENLABS_API_KEY=...    # ключ не хранится в репозитории
npm run voice     # озвучка + проверка всех якорей слов, таймлайн по сценам
npm run preview   # контакт-лист кадров → dist/preview.jpg
npm run build     # полный рендер → dist/<id>.mp4 + .srt
```

Предпросмотр конкретных моментов: `node engine/cli.mjs preview episodes/nsaids-growth-plates.json m:dwarfs+0.6 m:returns+0.5`.

Озвучка кэшируется в `cache/tts/` (ключ кэша = текст + голос + модель + настройки), поэтому повторные рендеры **не тратят символы**. Готовый кэш для текущего сценария лежит в репозитории — пересобрать видео можно даже без ключа.

## Как сделать новое видео

Весь эпизод — один JSON в `episodes/`:

- `script` — абзацы текста для озвучки (каждый абзац = отдельный запрос TTS и отдельная запись кэша).
- `voice` — голос/модель ElevenLabs, `speed`, `tempo` (доп. ускорение без смены тембра), `tighten` (максимальные паузы между словами/предложениями).
- `papers` — ссылки PubMed. Карточка формируется автоматически; `quote` + `highlight` добавляют цитату из абстракта с подсветкой слова.
- `marks` — именованные моменты (`"dwarfs": "@dwarfs"`), к которым привязаны анимации внутри сцен.
- `shots` — смена сцен по словам (`"at": "@twenty#2"` — второе слово «twenty» в тексте).
- `points` — куда и когда вояк показывает пальцем (`"target": "s2021.tibia"` — якорь, который регистрирует сцена).
- `cues` — звуки (`whoosh`, `tick`, `thud`, `blip`, `drop`) и тряска камеры.
- `captionRewrites` — как произнесённое превращается в подписи («Twenty oh six» → «2006», «COX two» → «COX-2»).

Синтаксис якорей: `@слово`, `@слово#2` (n-е вхождение), `@слово+0.4` (сдвиг), `@слово>` (конец слова). Если слова нет или вхождений меньше — сборка падает с понятной ошибкой, а не тихо съезжает.

Визуальная часть сцены — функция в `engine/stage/scenes.js`; общие детали (карточки, пилюли, штампы, стрелки, обводки маркером, рисунки статей) — в `parts.js`, научные схемы (кость, зона роста, фермент COX, клетки, чашка Петри) — в `diagrams.js`.

## Устройство

```
engine/
  cli.mjs        voice | preview | build
  tts.mjs        ElevenLabs /with-timestamps + кэш
  pubmed.mjs     ссылка PubMed → данные карточки (E-utilities, кэш)
  timeline.mjs   символы → слова → ужатые паузы → подписи → якоря
  audio.mjs      склейка блоков, atempo, процедурные звуки, липсинк,
                 компрессор + двухпроходный loudnorm до −14 LUFS
  render.mjs     Playwright: 4 параллельных вкладки, JPEG-кадры → ffmpeg (H.264 CRF 18)
  stage/         сама «сцена» (HTML/SVG): stage.js, scenes.js, parts.js, diagrams.js, presenter.js
tools/
  sources.mjs        откуда берётся каждый ассет
  fetch-assets.mjs   скачать исходники
  prepare-assets.mjs вырезать пилюли, обрезать вояков, собрать куклу ведущего, вырезать рисунки из PDF
  make-paper.mjs     сгенерировать бумажную текстуру фона
```

Каждый кадр — чистая функция от времени, поэтому кадры рендерятся в любом порядке и параллельно. Полный рендер 50-секундного ролика — около 2,5 минут на 4 ядрах.

Для отладки: `tools/shoot.mjs <секунды…>` — полноразмерные кадры, `tools/bench.mjs` — замер скорости кадра.

## Научная точность

Каждое утверждение в тексте сверено с абстрактом (PubMed), а цифры на экране взяты из статей:

| Время | Утверждение | Источник |
|---|---|---|
| хук, 2015 | НПВП подавляют пролиферацию хондроцитов зоны роста (в ролике — «slowed», без преувеличения); PGE2/простациклин это обращают; инъекции НПВП молодым мышам вызывают карликовость (dwarfism — дословно из абстракта) | Hutchison MR, White PC. Endocrinology 2015, PMID 25406016 |
| 2006 | Индометацин, кеторолак, диклофенак, пироксикам: подавление пролиферации, остановка цикла в G0/G1, апоптоз и некроз; простагландины эффект не обращают | Chang JK et al. Toxicology 2006, PMID 17045721 |
| 2011 | Связь COX-2 и BMP-2 при гипертрофической дифференцировке; ингибирование COX-2 её снижает | Welting TJM et al. Eur Cell Mater 2011, PMID 22183916 |
| 2017 | Кролики, целекоксиб 25 дней: изменения зоны роста, продвижение фронта минерализации 2436 → 1830 мкм | Janssen MP et al. Eur Cell Mater 2017, PMID 29039630 (рис. 4) |
| 2021 | Напроксен 10 недель: короче большеберцовая и бедренная кости; пролиферативная зона толще, гипертрофическая тоньше | Caron MMJ et al. J Orthop Res 2021, PMID 32740982 (рис. 2, 3) |
| твист | Флурбипрофен у молодых крыс: скорость продольного роста +30–40% | Li XJ et al. Bone 1989, PMID 2660884 |

В абстракте 2015 года не уточняется, какие именно НПВП кололи мышам, поэтому в тексте сказано «these drugs / NSAIDs», а не «ибупрофен». Сравнение двух мышей в этой сцене — схема, на экране помечено «schematic».

## Лицензии и важное

- **ElevenLabs:** ключ на бесплатном тарифе. Бесплатный тариф не даёт коммерческой лицензии на аудио — перед монетизацией нужен платный план. Ключ был отправлен в чат — после работы его лучше перевыпустить.
- Рисунки Caron 2021 — CC BY-NC-ND 4.0 (некоммерческое использование, без изменений; подписи с указанием источника — на экране). Рисунки Janssen 2017 — open access eCM.
- Пилюли — NLM C3PI (общественное достояние, правительство США). Вояки — wojakland.com. Ведущий — из исходного проекта.
